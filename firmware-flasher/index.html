Astro Orbit Flasher

Firmware ohne VS Code installieren. USB schreibt ein vollständiges Image; OTA aktualisiert einen bereits laufenden Astro-Orbit-Controller.

USB installieren

  1. Astro Orbit per USB anschließen.
  2. N.I.N.A., den seriellen Monitor und AstroOrbit.LocalServer.exe schließen.
  3. Auf „USB Firmware installieren“ klicken und den Port auswählen.
Falls „Failed to initialize“ erscheint
  1. BOOT am ESP32 gedrückt halten.
  2. Erneut auf Installieren klicken und den COM-Port wählen.
  3. Während „Preparing installation“ kurz EN/RESET drücken.
  4. BOOT loslassen, sobald die Verbindung hergestellt wurde.

Falls das Board keinen BOOT-Taster hat, GPIO 0 beim Reset kurz mit GND verbinden.

Die USB-Installation schreibt das vollständige Werksimage. Danach müssen die WLAN-Zugangsdaten gegebenenfalls neu eingerichtet werden.

    

    
OTA über WLAN

      
  1. Die normale astro-orbit-firmware.bin aus dem Release laden.
  2. Mit demselben Netzwerk wie Astro Orbit verbinden.
  3. Die Update-Seite des Controllers öffnen und die Datei auswählen.
